# dev_tools

Small utilities that ended up useful enough to keep.

## Contents

- `ackermann_test.py` - Test harness for Ackermann steering geometry.
- `bouncing_shape.py` - Demo of pyglet shapes with gravity and restitution.
- `circle_move.py` - Demo of moving a circle in pyglet.
- `circle_move_v2.py` - Second version of the circle move demo.
- `clock.py` - A simple digital clock drawn in pyglet.
- `color_fader.py` - Fades colors in pyglet.
- `context_block.py` - Port of claude-mem context block functions.
- `count_lines.py` - Count lines in files.
- `diary_summary.py` - Summarizes diary entries.
- `fetch_trending.py` - Fetches trending GitHub repos via API.
- `file_list.py` - Lists files in a directory.
- `json_to_csv.py` - Convert a JSON array of objects to CSV.
- `pattern.py` - Generates visual patterns in pyglet.
- `plot_trending.py` - Plots trending data.
- `recent_activity.py` - Shows recent file activity.
- `shapes.py` - Basic shapes demo in pyglet.
- `simple_logger.py` - A lightweight logger that rotates by file size.
- `size_check.py` - Checks file sizes.
- `sizes.py` - Utility for file sizes.
- `sort_trending.py` - Sorts trending data.
- `tail_file.py` - Print the last N lines of a file, like `tail -n`.

## Usage

Most of these are meant to be run from the command line. Check the file for arguments.
